# Accessibility statement

HPE Activity Hub is designed to make teaching and learning resources usable by as many people as possible. We aim to use semantic HTML, keyboard-friendly interactions, readable text, clear focus indicators, sufficient colour contrast, and reduced-motion preferences.

When adding new content, make sure that:

- images have meaningful alternative text, unless they are decorative;
- links say where they go;
- headings describe sections in order; and
- videos, downloads, and interactive activities have an accessible alternative where practical.

This site is continually improved as new material is added.
